# Common Tasks

| Task | Steps (summary) |
|------|-----------------|
| Launch a portal | App dashboard → Assigned Portals tile |
| Create order | OPMS → Create Order → save → submit |
| Find order | OPMS → Order Master → search/filters |
| Raise flag | Order detail → Flags → create |
| Add reminder | Reminders UI / order context |
| Upload attachment | Order/lead/expense attachment controls |
| Import via Google Sheet | Use sync/import UI where available (admin/configured) |
| Change password | Profile → Password change panel |
| Approve work plan | Work Planner → plan → Approve |
| Submit expense | Work Planner → Expenses → submit |
| Create quotation | Lead Manager → Quotations → New (manager/admin) |
| Assign user portal | User Manager → user/portals |
