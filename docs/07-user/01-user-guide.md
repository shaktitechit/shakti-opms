# User Guide

Welcome to the OPMS platform applications. This guide is based on the screens and routes present in the frontends.

Screenshot: Not available in repository.

## Applications you may use

| App | What it is for |
|-----|----------------|
| App (login hub) | Sign in and open your assigned portals |
| OPMS | Orders, parties, products, dispatch, transport planning |
| User Manager | Users, portals, departments, company branding (admins) |
| Lead Manager | Leads, follow-ups, quotations |
| Work Planner | Daily plans, visits, expenses |

## How access works
Your administrator assigns **portals** and **roles**. If you cannot open an app, you likely lack that portal assignment.
