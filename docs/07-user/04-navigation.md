# Navigation

## App Frontend
- Sidebar: roles under your department
- Main: Assigned Portals grid
- Topbar: theme, notifications, profile

## OPMS
Portal path prefix: `/admin`, `/sales`, `/finance`, `/dispatch`, `/account`, `/super_admin`

Typical sidebar groups (by role):
- Overview
- Order Master / Create Order
- Party Master / Product Master (not sales/dispatch limited views)
- Transport Agent Master / Transport Planner (dispatch-focused roles)
