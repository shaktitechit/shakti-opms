# FAQ

**Q: What is OPMS?**  
A: The operations portal for orders, masters, and logistics, part of a multi-app platform.

**Q: Why are there multiple websites?**  
A: Each domain (orders, leads, plans, users, login hub) is a separate app for clarity and access control.

**Q: Can one person have multiple roles?**  
A: Yes — users can hold multiple portal access_roles and department roles as assigned.

**Q: Where do I manage passwords for other users?**  
A: User Manager (admin). End users change their own password in Profile.

**Q: Is there a mobile app?**  
A: Not identified in this repository; use the responsive web apps.

**Q: Who do I contact for access?**  
A: Your system administrator / User Manager operator. Support escalation path: **Requires confirmation**.
