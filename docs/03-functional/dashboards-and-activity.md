# Module: Dashboards & Activity

## Purpose
Role-scoped KPI summaries and activity feed.

## Related APIs
- `GET /api/dashboard/admin|sales|finance|dispatch|account|super`
- `GET /api/activity`
- Order stats: `GET /api/orders/stats`, workflow-context
- Transport planner stats
- Work planner / lead manager dashboard stats on their services

## Related UI
Portal overview pages; App/User Manager KPI cards; Lead/Work dashboards
