Getting Started

  1. Open the App login URL (local default http://localhost:7013, production e.g. https://app.spspl.com).
  2. Sign in with the email and password provided by your administrator.
  3. On your department dashboard, open an Assigned Portal tile.
  4. The portal opens with single sign-on (?token= is applied automatically).
  5. Use the sidebar to navigate features for your role.

First-time tips

  • Change your password from Profile if available.
  • Ensure pop-up/redirects are allowed if an admin opens User Manager in an embed.
  • If branding looks wrong, your admin should update Company Information in User Manager.

Login

App Frontend

  1. Go to /
  2. Enter email and password
  3. Submit
  4. On success you reach /dashboard/...

Portal-specific login pages

OPMS, Lead Manager, Work Planner, and User Manager also expose / or /login if opened directly. Prefer the App hub when possible for SSO.

SSO

When launched from App, a token is passed in the URL once and stored in the browser session storage/cookies used by that app.

Logout

Use the user menu / logout control in the top bar (exact label may vary by app).

Problems

See Troubleshooting.

Feature Guides

Creating an OPMS order

  1. Login and open OPMS portal for your role.
  2. Go to Create Order.
  3. Select party and add products/quantities/rates as the form requires.
  4. Save draft.
  5. Submit when ready for workflow.
  6. Track status in Order Master / order detail tabs (approvals, dispatch, etc.).

Approving an order (finance/account/admin)

  1. Open order detail or approvals queue.
  2. Review line items and due sheet if present.
  3. Use Approve / Reject / Send to finance or account actions available to your role.
  4. Confirm status advanced in order header.

Transport planning

  1. Open Transport Planner.
  2. Create a plan for a date/agent.
  3. Add eligible orders.
  4. Submit and update packed/dispatched/delivered as operations proceed.

Managing a lead

  1. Open Lead Manager → Leads → New.
  2. Enter contact and requirement details.
  3. Assign and schedule follow-ups.
  4. Optionally create a quotation (manager/admin).
  5. Mark won/lost or convert when appropriate.

Creating a work plan

  1. Open Work Planner → Work Plans → New.
  2. Choose plan type and date.
  3. Add visits/works.
  4. Submit for approval (if required by your process).
  5. Check in/complete visits; submit expenses.

Admin: assign portal access

  1. Open User Manager → User Directory → user detail / portals.
  2. Assign portal codes and access roles.
  3. Ask the user to re-login via App hub.

Role Guides

OPMS — Sales

Purpose: Create and track sales orders.
Features: Overview, Order Master, Create Order.
Restrictions: Limited masters/nav vs admin; own-order emphasis on overview.

OPMS — Finance

Purpose: Commercial/financial review.
Features: Orders, approvals/finance queues, masters, transport planner (per nav).
Typical tasks: Review approvals, due sheets, risk flags.

OPMS — Account

Purpose: Account-stage review before dispatch.
Features: Similar masters to finance/admin per nav.
Typical tasks: Account approve/reject/amend.

OPMS — Dispatch

Purpose: Fulfillment and logistics.
Features: Orders, transport agents, transport planner; drivers/vehicles routes exist.
Typical tasks: Create dispatches, run transport plans, log deliveries.

OPMS — Admin / Super Admin

Purpose: Broad operational control; super admin also User Manager embed.
Features: Full masters + orders + transport; users via User Manager.

Lead Manager — Executive

Purpose: Personal pipeline.
Features: Leads, follow-ups, my reports.
Restrictions: No quotations/terms nav.

Lead Manager — Manager / Admin

Purpose: Team CRM + quotations.
Features: Full leads, quotations, terms, sales reports (admin labeling).

Work Planner — Executive

Purpose: Own daily plan and expenses.
Restrictions: No team manager sidebar.

Work Planner — Manager / Admin

Purpose: Approve plans/expenses; configure assignees.
Features: Team Manager / My Team + settings.

User Manager — Admin

Purpose: Identity & branding administration.
Features: Users, portals, departments/roles, company info.

User Troubleshooting

I can log in but portals are empty

Ask an admin to assign portals in User Manager.

OPMS says I don't have access

You need the opms portal with an access role (sales/finance/…). Re-login after assignment.

I opened a bookmark and must log in again

Sessions are browser-stored; use App hub launch for SSO. Clear stale tabs with old tokens.

Notifications not appearing

Check notification bell permissions; ensure you are logged in; ask ops if notification-service is down.

Upload failed

File service may be unavailable — contact administrator.

Wrong company logo/name

Admin updates Company Information; you may need a refresh.

FAQ

Q: What is OPMS?
A: The operations portal for orders, masters, and logistics, part of a multi-app platform.

Q: Why are there multiple websites?
A: Each domain (orders, leads, plans, users, login hub) is a separate app for clarity and access control.

Q: Can one person have multiple roles?
A: Yes — users can hold multiple portal access_roles and department roles as assigned.

Q: Where do I manage passwords for other users?
A: User Manager (admin). End users change their own password in Profile.

Q: Is there a mobile app?
A: Not identified in this repository; use the responsive web apps.

Q: Who do I contact for access?
A: Your system administrator / User Manager operator. Support escalation path: Requires confirmation.
